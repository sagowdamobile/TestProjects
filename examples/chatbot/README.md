# Simple Chatbot Example

A basic rule-based chatbot that demonstrates conversational AI concepts.

## What it does

This example implements a simple chatbot that:
- Recognizes patterns in user input using regular expressions
- Responds with appropriate messages based on the pattern
- Maintains a conversation flow
- Provides multiple response variations for natural conversation

## Installation

No external dependencies required! This example uses only Python standard library.

```bash
# Just run it!
python chatbot.py
```

## Usage

Run the chatbot:
```bash
python chatbot.py
```

Example conversation:
```
You: Hello!
Bot: Hi there! What's on your mind?

You: What can you do?
Bot: I'm a basic chatbot. I can respond to greetings, answer questions about myself, and have simple chats.

You: Thanks!
Bot: You're welcome!

You: Bye
Bot: Goodbye! Have a great day!
```

## How it works

This is a **rule-based chatbot** that uses:
- **Pattern matching**: Regular expressions to identify user intent
- **Response templates**: Pre-defined responses for each pattern
- **Randomization**: Multiple responses to make conversations feel more natural

This is a simple approach compared to modern AI chatbots, but it's great for learning the basics of conversational AI!
